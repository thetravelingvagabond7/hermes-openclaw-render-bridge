# Hermes/OpenClaw Render Bridge

This is a lightweight Telegram + OpenRouter bridge for controlling Hermes/OpenClaw-style workflows.

## Local setup

1. Copy .env.example to .env
2. Add your keys
3. Run:

npm install
npm start

## Render setup

Add these environment variables in Render:

TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID
OPENROUTER_API_KEY

Start command:

npm start
